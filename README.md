# MIND BATTLE v1.3 — 1000 вопросов

5 этапов, 21 вопрос в партии, по 200 вопросов на каждый этап.

ВНИМАНИЕ: расширение до 1000 сделано с помощью 937 автоматически сформированных математических задач и 63 ранее подготовленных вопросов. Это не 1000 уникальных энциклопедических фактов. Математические задания корректны по формулам, но для коммерческого игрового шоу рекомендована редакторская переработка банка.

В каждой партии вопросы выбираются случайно; при повторной игре система старается не повторять предыдущую партию. При перезапуске Render история не сохраняется.

## Обновление GitHub

Замените в корне `server.js`, добавьте `questions.json` (НОВЫЙ файл), а в папке `public` замените `index.html`. `package.json` можно оставить старым. Render автоматически перезапустит сервис.

**Важно:** обновите все три файла. Иначе сервер не найдёт `questions.json` или экран результатов будет показывать неверные варианты ответов.
