# MIND BATTLE — полная многопользовательская версия

5 этапов, 21 вопрос, 2–10 игроков, каждый сам за себя.

## Запуск локально

Установить Node.js 18+, затем в папке проекта:

```sh
npm install
npm start
```

Открыть http://localhost:3000.

## Бесплатная публикация через GitHub + Render

1. Создайте репозиторий на GitHub и загрузите **содержимое этой папки** (package.json, server.js, public/index.html) в корень репозитория.
2. Render → New → Web Service → Connect GitHub repository.
3. Language: Node. Build Command: `npm install`. Start Command: `npm start`.
4. Выберите бесплатный план, если доступен, и Deploy.
5. Полученную HTTPS-ссылку откройте на iPhone. Создайте комнату и отправьте ссылку друзьям.

## Правила начисления очков

- Ближе к истине: ближайший ответ +30, точный +50; при равенстве получают все ближайшие.
- Быстрее всех: правильный ответ +30; самый быстрый правильный +10 бонусом.
- Правда или блеф: правильный ответ +30.
- Аукцион: игрок вводит числовой ответ и ставку 1–100 очков, не выше своего текущего счёта; точный ответ +ставка, иначе −ставка. Для участия нужно минимум 1 очко.
- Финальная битва: правильный ответ +60.

## Ограничения первой версии

- Комнаты, ответы и очки хранятся только в оперативной памяти сервера: перезапуск или сон бесплатного хостинга сбросит игру.
- Комната поддерживает переподключение с того же браузера (localStorage).
- Если игрок отключился посреди вопроса, остальные ждут окончания таймера.
- Следующий вопрос запускает создатель комнаты вручную.
- Ускорение «Быстрее всех» считается по времени получения ответа сервером; задержка сети влияет на результат.
- Вопросы фиксированы, без административной панели и защиты от повторного прохождения.
- Это тестовая версия для компании друзей, не промышленный сервис.
